# Ethics

This project is an authorized, local-only university mini-lab.

The lab must only be used against services created by this repository on localhost or inside the Docker network. It must not be used against third-party systems, public IP addresses, campus networks, cloud hosts, or accounts that are not part of this lab.

The weak credentials are intentionally created inside Docker containers for demonstration. They are not real credentials and must not be reused anywhere else.

The wordlists are tiny and lab-only. They exist to demonstrate how weak passwords can be identified in a controlled environment and why stronger passwords reduce this risk.

The purpose of the project is education and defensive validation:

- understand how credential validation tools behave;
- compare vulnerable and secured configurations;
- document results responsibly;
- avoid harm to systems, accounts, and people.

Do not add stealth, evasion, persistence, post-exploitation, internet scanning, or arbitrary target support to this project.
